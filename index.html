· 1월 칸은 전년 12월 누적값을 그대로 이월한 값이며, 연간 타발수 = 최종 입력월 누적 − 1월 누적으로 계산합니다. 1월이 비어 있으면 첫 입력월을 기준으로 잡고 * 표시를 붙입니다.
· 대장 수식은 12월 칸을 기준으로 하여 연중에는 값이 음수로 나오지만, 여기서는 마지막 입력월을 기준으로 계산하므로 연중에도 점수가 정상 표시됩니다.
· 이 점수는 금형 등급(A/B/C) 평가의 1번 타발수 항목 배점이며, 등급은 13개 항목 합계로 결정됩니다.
· 등급 자동 산정 — 1번 타발수(누적)와 8번 금형제작년도(금형번호 앞자리)를 자동으로 읽어 총점을 다시 계산하고, A(20점 이하)·B(21~38점)·C(39점 이상) 등급을 금형에 반영합니다. 나머지 11개 항목은 기존 평가값을 유지하고, 평가 이력이 없는 금형만 기준값을 적용합니다. 등급이 바뀌면 점검주기와 연간 계획일정도 함께 재배정됩니다. F등급(A/S·단종)은 자동 산정에서 제외됩니다.
· 산정 방식 두 가지 — ①평가표 13항목(규정 기준)은 TJP-EU0702-01 그대로 총점으로 등급을 매기므로 타발수 항목(1~5점)만으로는 등급이 잘 바뀌지 않습니다. 규정에 맞는 방식입니다. ②타발수 구간 직접(간이)은 타발수만 보고 300만타 이상 → C등급 · 100만~300만타 → B등급 · 100만타 미만 → A등급으로 바로 지정합니다. 간이 방식은 평가표 산정 결과와 달라질 수 있어 등급 평가 탭에 등급 불일치로 표시되며, 고객 심사 대응 시에는 ①을 기준으로 관리하시기 바랍니다.
· 셀을 직접 수정하거나 MES 붙여넣기로 한 번에 반영할 수 있습니다.
· 잘못 입력했을 때는 상단의 타발수 삭제(선택한 연도·고객사·월 기준) 또는 초기 복원(대장 원본으로 전체 되돌리기)을 쓰세요. 지운 뒤 서버에 자동 저장됩니다.

정기세척 기준점 · 타발수 대장 연동

고객사품번금형번호 유형기준 타발수기준일출처 대장 누적타발수사용 타발수진행률

· 정기세척 판정은 타발수 관리 탭의 누적 타발수에서 자동으로 읽어옵니다. 사용 타발수 = 대장 최신 누적 − 기준 타발수이며, 양산금형 100만타 · A/S금형 50만타에 도달하면 정기세척 대상이 됩니다.
· 기준점은 마지막 정기세척 기록의 누적 타발수가 최우선이며, 기록이 없는 금형만 아래 표의 값을 씁니다. 신규 도입 시 [현재 누적타발수로 기준점 설정]을 한 번 눌러 시작점을 잡아 주세요.
· 표의 기준 타발수 · 기준일 칸은 직접 수정할 수 있습니다 (실제 세척일 기준으로 맞출 때 사용).
· 타발수 기준 초기 세팅 — 도입 시 한 번만 실행합니다. 누적 타발수가 한도(양산 100만 · A/S 50만)를 넘은 금형은 오늘자 정기세척 완료로 기록하고 기준점을 현재 누적값으로 잡아 0%로 리셋하며, 넘지 않은 금형은 기준점 0타로 두어 지금까지의 누적 타발수가 그대로 진행률에 반영되게 합니다. 세척 이력이 이미 있으면 실행되지 않으니, 다시 하려면 이력을 비운 뒤 실행하세요.

세척 이력 데이터

세척 이력은 정기점검 데이터와 분리해 kv_store 테이블의 mold_wash_v1 키에 저장됩니다. 금형 마스터는 설정 → 금형 마스터를 그대로 공유하므로 별도 등록이 필요 없습니다.

Supabase 연결

자동 연결 서버에 연결하는 중입니다…

금형 수리관리 시스템과 같은 프로젝트(ebthltdmxpzlkfwvdloz)의 kv_store 테이블 mold_periodic_v1 키를 사용합니다. 페이지를 열면 자동으로 연결되어 서버 데이터를 불러오고, 입력 내용은 자동 저장됩니다.

금형 마스터

금형 등록·수정·삭제. 등록하면 점검 대상·연간 계획·타발수·등급 평가에 자동 반영됩니다.

타발수 대장에는 있는데 금형 마스터에 없는 품번(등급 미등록 표시)을 한 번에 등록합니다. 고객사·모델·사용기계는 대장 값을 그대로 가져오고, 등급은 위에서 고른 값으로 잡은 뒤 연간 계획까지 자동 배정합니다. 금형번호는 비어 있으니 등록 후 금형 마스터에서 채워 주세요.
